# Database

## Purpose
Foundation database for the Smart Used-Car Decision Support System.

## Technology
- PostgreSQL
- Backend integration: Member 01 / Spring Boot
- Data ingestion: Member 03
- Decision-support data: Member 05
- Prediction fields: supplied later by Member 04 through the pricing workflow

## Important
`schema.sql` is an initial design derived from the project workflow. The workflow does not define a final database schema, so naming, constraints and additional entities must be confirmed by the team before production implementation.
